# 앱 화면 흐름

> 출처: 2026-08-06 플로우 스케치 + 충돌 해소 (2026-08-06)  
> 앱: 소비자 / 사회복지사 2개 + 서버  
> 앱 이름 후보(Later): 영웅 / 손길 / 동행  
> 상세 정책: `product-spec.md`

---

## 1. 소비자 앱 흐름

```
사용자 앱 시작화면
  → 회원가입 (이메일 / Google / Apple / Naver / Kakao)
  → 기본설정 (역할: 사용자, 주소)
  → 홈
  → 카테고리 선택
  → 세부 카테고리 선택
  → 일정 선택 (정기 / 일회)
  → 예상 가격 안내
  → 신청 요약 → 도움 요청
  → 매칭 (복지사 지원 → 별점순 목록 → 소비자 선택 / 1명이면 자동)
  → 매칭 후: 프로필 확인 · 채팅 가능
  → 서비스 수행
  → 서버
```

### 상주 (건별과 분리)

```
상주 진입 → 선택사항 체크 → 상담 신청 완료 → 1:1 전화상담
```
(1차: 상담 신청만)

---

## 2. 사회복지사 앱 흐름

```
사회복지사 앱 시작화면
  → 회원가입
  → 기본설정 (자격증·면허)
  → 홈 (도움 요청 목록)
  → 요청 상세 (할 일 · 날짜 · 위치 · 예상 가격)
  → 지원 / 수락
  → 매칭 확정 시 채팅 가능
  → 서비스 수행
  → 서버
```

---

## 3. 서비스 완료 이후 (확정 — 다이어그램)

```
도움 완료 처리
  → 사용자에게 결제 요청 (기한 내 결제)
  → 입금 확인 후 사회복지사 정산 (**플랫폼 수수료 15%** 차감)
  → 도움·매출 데이터 기록 (내부)
  → 사용자 리뷰
```
