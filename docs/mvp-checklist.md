- [ ] 신청 요약 → 제출

### Must — 매칭

- [ ] 매칭 대기
- [ ] 1명 자동 / 여러 명 별점순 직접 선택
- [ ] 재요청 1회 · 조건 조정 · 고객센터

### Must — 상주

- [ ] 선택사항 체크 → 상담 신청 완료 → 1:1 전화상담
- [ ] 상담 신청 이력

- **확정:** 상담 신청만 (구독 결제 없음)

### Must — 결제·취소

- [ ] 도움 **완료 후** 결제 요청

- [ ] 취소 수수료 안내 (24h / 12h / 노쇼)

### Must — 매칭 이후

- [ ] 채팅 (**매칭 후에만**)
- [ ] 리뷰 / 평가
