## 화면 2: 홈 — 카테고리 그리드

이전 카드 배열 명세는 **아래 내용으로 대체**한다. (시안 C 배열, 2026-10-17)

- 카테고리 그리드: 2열 × 3행, 카드 높이 136, radius 20, 흰 배경, 테두리 1.5 border, 카드 안쪽 패딩 위아래 14 좌우 12, 카드 간격 12
  - 카드 안 배열: 왼쪽 위에 이름(28px bold, 한 줄 고정, 줄바꿈 금지), 그 바로 아래 4px 간격으로 설명(16px textSecondary, 한 줄 제한), 오른쪽 아래 모서리(오른쪽·아래에서 10px)에 아이콘 원(48px, orangeSoft 배경, 아이콘 28px accentIcon)
  - 이름과 설명이 아이콘 원과 겹치지 않아야 한다
  - 카드 6개는 스크롤 없이 한 화면에 다 들어온다

  - 케어 / 부축·병원 동행 / heart
  - 청소 / 정돈·용변처리 / sparkles
  - 음식 / 배달·식사 도움 / utensils
