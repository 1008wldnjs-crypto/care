## 3. 현재 구현 상태

### care-consumer — 홈·시안 반영 / 예약 플로우는 명세만 갱신

첫 화면·홈·예약 내역·내 정보 시안 반영됨. 첫 화면에는 일러스트 칸이 없다. 홈 카드는 시안 C. 운동 설명은 `산책·홈트`.  
**예약 1~5 코드:** 주소 → 일정 → 케어 항목 → 연락처 → 최종 확인. 최종 확인은 주소, 연락처, 일정, 서비스 품목, 예상 금액, 요청사항 한 줄(「요청사항이 있다면 미리 적어주세요」, 없어도 됨). 동의 체크는 없다. 「신청하기」는 매칭 대기로 간다. 사회복지사 앱이 연결되기 전에는 지원자가 없으므로 담당자 고르기로 넘어가지 않는다. 결제는 서비스가 끝난 뒤. 일정 시트는 이번 주 일요일부터 4주 달력(칸 크기 유지, 넘치면 날짜만 스크롤), 시작 시간은 오전 8:00–오후 8:00 휠. 저장된 연락처는 미리 보여 준다. 주소가 이미 있으면 「다음으로」에서 「이 주소가 맞습니까?」를 한 번 더 묻는다. 이용 시간은 `perHour`(운동·청소·인지 활동, 임시)만. 케어·음식은 `perItem`이라 이용 시간을 숨기고 `durationHours`는 null. 당일 긴급은 방문 카테고리를 먼저 고른 뒤 시작한다.  
홈 상주 카드 설명은 「전화 상담」. 실시간은 큰 제목·「내 정보」·안내 문구·「예약하기」. 대화하기는 매칭 없으면 같은 빈 안내, 매칭 있으면 「대화 열기」→채팅.  
내 정보 하위: 프로필(예약 연락처), 결제수단 관리(등록 수단), 공지(목), 환경설정(푸시·알림톡 스위치·연동 전), 사회복지사 지원(안내+고객센터). `PlainScreen`.  
매칭 대기·담당자 선택·매칭 완료·예약 내역은 예약 단계와 같이 제목 30px, 본문 16px 이상, 카드 모서리 20, 높이 60 버튼크기. 담당자 고르기 카드에서 경력은 굵은 한 줄, 후기 한 줄은 따옴표 칸으로 구분한다. 매칭 완료 카드에는 후기 수를 두지 않는다.  
예약 내역 카드 → `MyRequests`(예약 상세): 확정=채팅·서비스 완료 처리 / 결제 대기=결제·채팅 / 결제 완료=리뷰. 매칭 완료의 「예약 내역 보기」는 히스토리 탭으로.  
채팅·결제·리뷰도 예약 단계와 같은 톤(제목 30px·카드 20·본문 16+·버튼 60, 자체 뒤로). 결제는 결제수단 등록과 같은 행 선택 UI. 채팅 말풍선은 orangeSoft.  
공통 `ui.tsx`: Title 30px, Card/Chip radius·border·16px+ 시안 토큰.  
금액은 pricing 설정만 본다. **전 카테고리 시간당 16,000원.** 사회복지사 13,000원, 앱 3,000원. 긴급 시 +30%. 매칭 확인의 「확인」 다음에 결제수단 등록이 있다. 위부터 신용카드, 계좌이체, 카카오페이(노랑), 네이버페이(초록). 여기서는 청구하지 않는다. 서비스 종료 후 목 결제 화면도 같은 순서다. 상주는 전화 상담.  
예약은 `BookingFlow`만. 구형 `Schedule`/`PickService`/`SubCategory`/`PriceEstimate`/`RequestSummary`·미사용 `Live`/`Talk` 화면 제거.  
주소: 홈 「주소 입력」·예약 시트 모두 도로명·상세 직접입력(네이버 연동 전). 「현재 위치로 찾기」를 누를 때만 위치 허용. 허용하면 도로명만 채운다. 동·호는 직접. 도로명+상세 필수.  
상주 상담·고객센터: 예약 톤(제목 30·입력 radius 20·버튼 60). 고객센터는 앱 안 문의만.  
로그인(`SignUp`): 제목 30·자체 뒤로·카카오/네이버/휴대폰. `AuthButtons`에 start/login 문구. 실연동 전.  
주요: `BookingFlowScreen`, `StartScreen`/`SignUpScreen`, `SupportScreen`, `ResidentConsultScreen`

### care-caregiver — 목 UI 완료 · 소비자와 같은 톤

피드 → 지원 → 일정 → 채팅 → 완료 → 정산(18.75%). 플로우는 그대로.  
톤: Pretendard, 주황 버튼(`#FF8A1F` + 진한 글자), 카드 모서리 20, 제목 30px.  
의뢰 카드·상세는 소비자 예약 필드에 맞춤: 도움 항목·일정·긴급·반복·지역·돌봄 받는 분·요청사항·예상 금액(16,000/h). 상세 주소는 매칭 후.  
주요: `src/theme/colors.ts`, `src/types/jobs.ts`, `src/services/jobStore.ts`

- 운동은 세부 선택에서 금액을 숨긴다. 금액은 일정 다음 예상 가격 화면에서 보여 준다.
- 주요 버튼 배경은 `#D9691F`, 눌렀을 때는 `#C2570C`. 글자는 흰색 18px 굵게. 같은 날 네 화면 시안으로 이 색은 대체됨.
